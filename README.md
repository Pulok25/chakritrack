ChakriTrack
A job application tracker built with React, Tailwind CSS, and Firebase.
Live Demo: https://chakritrack.vercel.app
Features

User authentication (Firebase)
Add, update, and delete job applications
Track application status (Applied, Interview, Rejected, Offered)
Responsive dashboard

Tech Stack:
  React
  Tailwind CSS
  Firebase (Auth + Firestore)
  Vite

Run Locally:
bash: git clone https://github.com/Pulok25/chakritrack
      cd chakritrack
      npm install
      npm run dev
